DESCRIPCIÓN DEL PROYECTO:

Esta aplicación permite a un médico registrarse por única vez, iniciar sesión 
con credenciales seguras y gestionar una base de datos de pacientes.
se implementaron las pruebas unitarias usando la librería unittest
para validar la lógica de login y creación de modelos y manejo ded historial

REQUISITOS:

-python 3.14.3
-Tkinter (por lo que se viene incluido en python)
